AI-powered blog post generator using OpenAI and Pexels APIs. Create engaging content with automatic image selection and SEO optimization.

== Description ==

BeastPost is a powerful WordPress plugin that leverages artificial intelligence to help you create engaging blog posts. It uses OpenAI's GPT-4 to generate high-quality content and Pexels API to automatically add relevant featured images.

= Features =

* Generate complete blog posts from simple subject inputs
* Automatic SEO-optimized URL generation
* Automatic featured image selection and integration
* WordPress block editor (Gutenberg) compatible
* Easy API key management
* Download generated content as text file

= Requirements =

* WordPress 5.8 or higher
* PHP 7.4 or higher
* OpenAI API key
* Pexels API key

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/beastpost` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the Settings->BeastPost screen to configure the plugin.
4. Enter your OpenAI and Pexels API keys in the settings.

== Frequently Asked Questions ==

= Do I need API keys? =

Yes, you need both an OpenAI API key and a Pexels API key to use this plugin. You can get these from:
* OpenAI: https://platform.openai.com/api-keys
* Pexels: https://www.pexels.com/api/

= What version of WordPress is required? =

BeastPost requires WordPress 5.8 or higher.
